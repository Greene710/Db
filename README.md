# ShopDB — практическая работа по SQL

Практическая работа по созданию базы данных интернет-магазина **ShopDB** и решению четырёх задач на SQL.

**СУБД:** MySQL 8.0+

## Структура базы данных

| Таблица | Поля |
|---|---|
| `Customers` | CustomerID, FullName, City |
| `Orders` | OrderID, CustomerID, OrderDate, TotalAmount |
| `OrderDetails` | OrderID, ProductID, Quantity, Price |
| `Products` | ProductID, ProductName, CategoryID, Price |
| `Categories` | CategoryID, CategoryName |

Связи:
- Один клиент может иметь много заказов.
- Один заказ может содержать несколько товаров.
- Каждый товар относится к категории.
- `OrderDetails` связывает заказы и товары.

## Файлы

- **[shopdb.sql](shopdb.sql)** — создание базы данных и таблиц, затем запросы для всех задач.
- **[answers.md](answers.md)** — разбор запросов, SQL-команд и ответы на вопросы для защиты.

## Как запустить

1. Откройте MySQL Workbench или другой клиент MySQL.
2. Откройте файл `shopdb.sql`.
3. Выполните скрипт целиком.
4. Запросы расположены после создания таблиц.

> Для получения результатов запросов нужно предварительно добавить тестовые данные в таблицы.

## Решённые задачи

1. ТОП-5 клиентов по сумме покупок за последние 30 дней.
2. Количество клиентов и средний чек по городам, где средний чек больше 5000.
3. Количество проданных единиц и выручка по категориям с использованием цены из `Products`.
4. Поиск клиентов без заказов двумя способами: `NOT IN` и `LEFT JOIN`.
